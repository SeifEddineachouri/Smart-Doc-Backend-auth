🔐 GitHub Secrets Setup Guide

Configure Required & Optional Secrets for SmartDoc CI/CD Pipeline

❌ What Went Wrong?

GitHub Actions Pipeline Failures

The CI/CD pipeline failed because required secrets (API keys, credentials, tokens) were not configured in your GitHub repository.

The workflow requires credentials for:

  • Docker Hub (push images)
  • SonarQube (code analysis)
  • Kubernetes (cluster deployment)
  • Slack (notifications - optional)

📋 Secret Status Legend

🔴 Required Must be configured for basic CI/CD to work
🔵 Optional Nice to have, pipeline works without it

🔑 Required & Optional Secrets

Secret Name Status Description Where to Get It
DOCKER_USERNAME Optional Your Docker Hub username Docker Hub account
DOCKER_PASSWORD Optional Docker Hub access token (not password) Docker Hub → Account → Security
SONAR_TOKEN Optional SonarCloud authentication token SonarCloud → My Account → Security
KUBE_CONFIG Optional Kubernetes cluster config (base64 encoded) Your K8s cluster
SLACK_WEBHOOK_URL Optional Slack webhook for notifications Slack app configuration
✓ Good News: The pipeline now handles missing secrets gracefully. It will build successfully even if secrets aren't configured, but Docker push and K8s deployment will be skipped.

📝 Step-by-Step Setup

Step 1: Navigate to GitHub Repository Settings

  1. Go to: https://github.com/YOUR_USERNAME/Smart-Doc-Backend-auth
  2. Click "Settings" tab
  3. In left sidebar, click "Secrets and variables"
  4. Select "Actions"

Step 2: Add Docker Hub Credentials

Click "New repository secret" and add:

Name: DOCKER_USERNAME
Value: your-docker-hub-username
Name: DOCKER_PASSWORD
Value: your-docker-hub-access-token
ℹ️ How to get Docker Hub token:
  1. Go to Docker Hub
  2. Login → Account → Security
  3. Click "New Access Token"
  4. Name it "GitHub Actions"
  5. Copy the token (it won't show again)

Step 3: Add SonarCloud Token (Optional)

Click "New repository secret" and add:

Name: SONAR_TOKEN
Value: your-sonarcloud-token
ℹ️ How to get SonarCloud token:
  1. Go to SonarCloud
  2. Login → My Account → Security
  3. Generate Tokens
  4. Name it "GitHub Actions"
  5. Copy the token

Step 4: Add Kubernetes Config (Optional - for K8s Deployment)

First, encode your kubeconfig file:

# On Linux/Mac:
cat ~/.kube/config | base64 | pbcopy

# On Windows (PowerShell):
$content = Get-Content ~/.kube/config -Raw
[Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes($content)) | Set-Clipboard

Then create the secret:

Name: KUBE_CONFIG
Value: [paste your base64-encoded kubeconfig here]
⚠️ Security Warning: Keep your kubeconfig private! Never commit it to Git.

Step 5: Add Slack Webhook (Optional - for Notifications)

ℹ️ How to get Slack Webhook URL:
  1. Go to Slack App Directory
  2. Search "Incoming Webhooks"
  3. Click "Add to Slack"
  4. Select channel for notifications
  5. Copy Webhook URL

Then create the secret:

Name: SLACK_WEBHOOK_URL
Value: https://hooks.slack.com/services/YOUR/WEBHOOK/URL

⚡ Minimal Setup (For Testing)

Start with Just Build & Tests

The updated workflow now builds successfully without Docker/K8s secrets!

Steps:

  • You don't need to add Docker, SonarQube, or K8s secrets
  • Pipeline will build code and run tests
  • Docker build will happen locally (not pushed)
  • K8s deployment will be skipped
  • Later add secrets when ready for full CI/CD
✓ Best Practice: Start with minimal setup to verify the basic pipeline works. Then add Docker/K8s secrets when ready.

🔧 Troubleshooting

Pipeline Still Failing?

Check Workflow Status

  • Go to your repository → "Actions" tab
  • Click the failed workflow run
  • Check the error message in logs
  • Look for "Error: secret not found" or similar

Verify Secrets Are Set

  • Go to Settings → Secrets and variables → Actions
  • Verify all secrets appear in the list
  • Secrets show as "***" when set correctly
  • If blank/missing, add them again

Test Simple Build First

Don't add all secrets at once. Test the build stage first:

  • Make a test commit
  • Watch Actions tab for build job
  • If build passes, add Docker secrets
  • Then add K8s secrets
⚠️ Common Issues:
  • Base64 decode error: KUBE_CONFIG might be corrupted - re-encode it
  • Docker push fails: Token might be expired - generate new one
  • SonarQube fails: Token might be wrong organization - verify it's correct
